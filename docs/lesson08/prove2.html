08 Prove: Bill of Materials Calculator

Purpose

Prove that you can write a Python program that uses a dictionary to efficiently store and retrieve data, and use lists to manage complex data structures.

Problem Statement

In manufacturing, a Bill of Materials (BOM) is an exhaustive list of raw materials, assemblies, and sub-assemblies needed to manufacture a product. For example, a bicycle's BOM includes the frame, handlebars, and two wheels. Each wheel is a sub-assembly containing a rim, a tire, and 28 spokes.

Engineers use a BOM Calculator to estimate the total cost of production. The calculator needs to look up the unit cost of every individual part and multiply it by the quantity required, even when parts are grouped inside sub-assemblies.

Assignment

Write a Python program named bom_calculator.py that calculates the total cost of an assembly. Your program must do the following:

  1. Convert a provided compound list of parts into a dictionary where the Part ID is the key.
  2. Read a BOM string (e.g., "Frm:1, (Rim:1, Spk:28):2") from the user.
  3. Calculate the total cost by looking up each part's unit cost in the dictionary.

Steps

  1. Download bom_parser.py and bom_catalog.py.
  2. At the top of bom_calculator.py, import the necessary functions: 
    from bom_parser import parse_bom
from bom_catalog import get_parts_catalog
  3. Write a function named make_catalog_dict that takes the list from get_parts_catalog() and returns a dictionary organized like this: 
    {
    "Frm": ["Frame", 150.00],
    "Rim": ["Rim", 25.00],
    ...
}
  4. Write calculate_assembly_cost(parts_list, catalog_dict). The parts_list is returned by the parse_bom function. For each part in the list, look up its cost in the dictionary and add the total to a running sum.
  5. Write the main function to handle user input and display the final results.

Testing Procedure

  1. Run your program with the following inputs: 
    > python bom_calculator.py
Enter the BOM string: Frm:1, Hnd:1, Sdl:1, (Rim:1, Spk:28, Tir:1):2

Total Assembly Cost: $313.00
