06 Prove: Flight Path & Fuel Calculator

Purpose

Prove that you can write a Python program with complex mathematical functions, verify those functions using pytest, and troubleshoot logic errors using the VS Code debugger.

Problem Statement

Pilots must carefully plan their flights to ensure they have enough fuel to reach their destination, plus a safety reserve required by law. This planning involves calculating the distance over the Earth's curved surface, adjusting for wind speed (which affects how fast the plane moves relative to the ground), and accounting for the extra fuel burned during the climb to cruising altitude.

Assignment

Write a Python program named flight_planner.py and a corresponding test file test_flight_planner.py. Your program will help a pilot calculate the total fuel required for a trip between two locations. Because you should have learned how to write and test functions in previous lessons, this assignment will focus on using those skills to solve a more complex problem and using the debugger to find mistakes.

Steps

In flight_planner.py, write the following functions and verify them with corresponding test functions in test_flight_planner.py.

  1. Calculate Distance: Write haversine_distance(lat1, lon1, lat2, lon2). Use the Haversine formula to calculate the distance in kilometers between two points.

    Where r (Earth's radius) is 6,371 km. Note: All trigonometric functions in Python's math module expect angles to be in radians.
  2. Adjust for Wind: Write ground_speed(airspeed, wind_speed). For this assignment, assume a direct headwind or tailwind. A tailwind (positive wind_speed) increases the plane's speed relative to the ground. A headwind (negative wind_speed) decreases it. Ground Speed = Airspeed + Wind Speed.
  3. Fuel Burn: Write fuel_burn_rate(speed, burn_coefficient). Calculate liters per hour using: rate = burn_coefficient × speed1.2 / 100.
  4. Required Fuel: Write total_fuel(distance, ground_speed, burn_rate). Total Fuel = (Distance / Ground Speed × Burn Rate) + 15.0 liters (safety reserve).
  5. Copy and paste the following code at the bottom of your flight_planner.py program. 
    # Constants for a standard light aircraft
CRUISE_AIRSPEED = 200.0     # (km/h)
FUEL_BURN_COEFFICIENT = 5.0  # (unitless)

def main():
    # Get the coordinates of the two locations.
    print("Please enter the GPS coordinates for your flight path.")
    lat1 = float(input("Departure latitude: "))
    lon1 = float(input("Departure longitude: "))
    lat2 = float(input("Destination latitude: "))
    lon2 = float(input("Destination longitude: "))

    # Get the wind speed.
    wind_speed = float(input("Wind speed in km/h (negative for headwind): "))

    # Call the haversine_distance function to calculate the distance.
    distance = haversine_distance(lat1, lon1, lat2, lon2)

    # Call the ground_speed function to calculate the ground speed.
    gs = ground_speed(CRUISE_AIRSPEED, wind_speed)

    # Call the fuel_burn_rate function to calculate the burn rate.
    burn_rate = fuel_burn_rate(gs, FUEL_BURN_COEFFICIENT)

    # Call the total_fuel function to calculate the required fuel.
    fuel = total_fuel(distance, gs, burn_rate)

    # Print the results for the user to see.
    print(f"\nFlight Summary:")
    print(f"Distance: {distance:.1f} km")
    print(f"Ground Speed: {gs:.1f} km/h")
    print(f"Required Fuel: {fuel:.1f} liters")


if __name__ == "__main__":
    main()
