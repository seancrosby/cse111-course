10 Prove: Medical Lab Results Analyzer

Purpose

Prove that you can write a Python program that reads CSV files, populates a dictionary, processes a list of transactions, and handles common exceptions like FileNotFoundError, KeyError, and ValueError.

Problem Statement

A medical clinic needs a program to process patient blood test results. The program must compare a patient's results against a catalog of "Normal" reference ranges. If a result is outside the range, the program should flag it as "High" or "Low". This helps doctors quickly identify potential health issues.

Assignment

Write a Python program named lab_analyzer.py that processes two CSV files and prints a summary report. Your program must do the following:

  1. Read lab_tests.csv into a compound dictionary using the test code as the key.
  2. Read patient_results.csv and look up each test name and range.
  3. Determine the status (Normal, High, or Low) for each result.
  4. Count the total number of tests and the number of abnormal results (High or Low).
  5. Include robust error handling for missing files, unknown codes, and invalid numeric data.
  6. Print the current date and time at the bottom of the report.

Help

Helpful Documentation

Steps

  1. Download lab_tests.csv, patient_results.csv, and test_lab_analyzer.py.
  2. In lab_analyzer.py, write a function named read_dictionary(filename, key_column_index) that reads a CSV file into a dictionary.
  3. Write a function get_status(result, min_val, max_val) that returns "Normal" if the result is between min and max (inclusive), "High" if it is above max, and "Low" if it is below min.
  4. In main, wrap your core logic in a try block and add except blocks to handle:
    • FileNotFoundError: Print a message identifying the missing file.
    • KeyError: Print a message identifying the unknown test code.
    • ValueError: Print a message identifying invalid numeric data in the CSV.

Testing Procedure

  1. Run pytest test_lab_analyzer.py and ensure your helper functions pass.
  2. Run your program and verify the output matches this format:

Common Mistake

Losing Data in the Results File

Because some patients may have multiple results for the same test (like the two Glucose tests in patient_results.csv), your program should not read the patient_results.csv file into a dictionary. If you do, the second result will overwrite the first. Instead, read and process each row of the results file one by one in a loop.
