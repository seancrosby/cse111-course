04 Prove: Dynamic Recipe Generator

Purpose

Prove that you can write functions with parameters, call functions from within other functions, and manage variable scope effectively.

Problem Statement

Cooking for a large group or just for yourself requires scaling recipes. A recipe for 4 people doesn't work for 12 without some math. Digital cookbooks often have a feature where you can enter the number of servings you want, and the program automatically updates the quantities and the cooking instructions.

Assignment

Write a Python program named recipe.py that generates a scaled recipe and a shopping list. Your program must include at least these seven functions:

  1. main
  2. make_recipe
  3. get_ingredient
  4. get_instruction
  5. scale_quantity
  6. get_prep_time
  7. get_shopping_item

The core logic of your program should follow these rules:

  • The main function should ask the user for the recipe name and the number of desired servings.
  • The make_recipe function should coordinate the calls to the other functions to build a single, multi-line string representing the full recipe.
  • The scale_quantity function should take a base quantity (designed for 4 servings) and scale it to the desired number of servings.

Help

Helpful Documentation

  • The preparation content for this lesson explains variable scope and how to call a function from inside another function.
  • To format numbers to one decimal place, use an f-string like this: f"{amount:.1f}".

Steps

Do the following:

  1. Write the scale_quantity(base_qty, servings) function. It should return base_qty * servings / 4.
  2. Write the get_prep_time(servings) function. It should return an estimate like 20 + (servings * 2) minutes.
  3. Write the get_ingredient(item, base_qty, unit, servings) function. This function must call scale_quantity and return a formatted string like "1.5 cups of Flour".
  4. Write the get_instruction(verb, item) function. It should return a simple string like "Whisk the Flour until smooth."
  5. Write the get_shopping_item(ingredient_string) function. This function should take an ingredient string (like "1.5 cups of Flour") and use the split() method to extract and return just the last word (the item name).
  6. Write make_recipe(name, servings). This function will call get_prep_time, get_ingredient and get_instruction multiple times to build a complete recipe string.

Testing Procedure

Verify that your program works correctly by following these steps:

  1. Run your program and enter the inputs shown below. 
    > python recipe.py
Enter the recipe name: Sugar Cookies
Enter the number of servings: 8

--- Sugar Cookies (8 servings) ---
Prep Time: 30 minutes

Ingredients:
2.0 cups of Flour
1.0 cups of Sugar
0.5 lbs of Butter

Instructions:
1. Whisk the Flour until smooth.
2. Mix in the Sugar.
3. Melt the Butter and stir.

Shopping List:
- Flour
- Sugar
- Butter

Exceeding the Requirements

To exceed the requirements (earn the final 7%), consider these features:

  • Add a get_random_tip() function that randomly chooses a cooking tip from a list and adds it to the bottom of the recipe.
  • Handle the case where the user enters 0 or a negative number for servings by providing a default of 4.
