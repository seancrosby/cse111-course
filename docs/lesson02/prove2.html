02 Prove: Compound Interest Calculator

Purpose

Prove that you can write a Python program that performs complex arithmetic, calls functions to get the current date, and appends values to a text file.

Problem Statement

Understanding how money grows over time is a critical skill for financial planning. Compound interest is the interest on a loan or deposit calculated based on both the initial principal and the accumulated interest from previous periods. Financial advisors often use simple programs to log various scenarios for their clients to compare different investment strategies.

The formula to calculate the future value of an investment with compound interest is:

A = P 1 +
r
n
nt
  • A is the final amount (future value).
  • P is the principal amount (initial investment).
  • r is the annual interest rate (as a decimal).
  • n is the number of times interest is compounded per year.
  • t is the number of years the money is invested.

Assignment

Write a Python program named investment.py that does the following:

  1. Reads from the keyboard the four values needed for the formula: principal, annual interest rate (as a percentage), number of times compounded per year, and the number of years.
  2. Computes and outputs the future value of the investment.
  3. Gets the current date from the computer’s operating system.
  4. Opens a text file named investments.txt for appending.
  5. Appends to the end of the investments.txt file one line of text that contains the following six values:
    1. current date
    2. principal amount
    3. annual interest rate (percentage)
    4. compounds per year
    5. number of years
    6. future value
